#CD4511 decoder: number → digit

What it does: it reads a number from 0 to 9 written in binary on 4 wires (A = 1, B = 2, C = 4, D = 8: that's called BCD, binary-coded decimal), and lights the right segments of a 7-segment display. Give it 0110 (4 + 2 = 6) and it lights a, f, g, e, d, c: a "6". It also drives the segments itself, with up to ~25 mA each.

How it works inside: a small latch (a 4-bit memory) holds the number, then a decoder made of logic gates works out which of the 7 segments each number needs (a hard-wired lookup table, like the 27-diode matrix of dice project 14), and 7 output transistors push current into the segments. Three control pins: LT (lamp test: all on), BI (blank: all off) and LE (latch: freeze the digit).

Water analogy: a fountain with 7 nozzles shaped like a digit. You set 4 levers (on/off), and a mechanism behind the wall opens exactly the nozzles that spray the shape of that number.

Click the 4 input bits (or the controls) to see what the display shows. Numbers above 9 (1010–1111) are not valid BCD: the 4511 shows nothing.

Only for common-cathode displays like your SC39-11SURKWA (COM to ground). Each segment still needs its own resistor (470 Ω–1 kΩ at 5–9 V). Used in project 15, project 19 and Using real parts.
